## 🆕 Что нового в v1.10.1

Большой релиз надёжности по итогам полного аудита кода:

- 🛡️ **Безопасность**: закрыты выполнение чужих команд через настройки, DNS-rebinding и CSRF; секреты не уходят в настройки и бэкапы; бот слушается только владельца; AdGuard не виден из сети провайдера.
- 🌐 **Интернет и DNS не пропадают**: быстрый failover без ожидания уведомлений, точная проверка интернета, изолированный тест скорости, IPv6 не обходит белые списки, DNS AdGuard автоматически подстраховывается.
- 🚀 **Zapret**: правила перестраиваются при любом включении и выключении, системные DNS роутера больше не трогаются, правила брандмауэра не накапливаются.
- 💾 **Настройки не теряются**: надёжная запись и автоматическое восстановление конфигурации после сбоя питания; фоновые механизмы не перетирают ваш выбор; настройки устройства следуют за ним при смене IP.
- 📦 **Подписки**: рабочие Shadowsocks/VMess из v2ray-подписок, защита от «ломающих» символов, никакой самовольной смены формата.

Подробный список — в [DEVELOPMENT.md](DEVELOPMENT.md#v1101--большая-работа-над-надёжностью-интернет-и-dns-не-пропадают-настройки-не-теряются-безопасность-усилена), технический журнал исправлений с тестами — в [docs/FIX_LEDGER.md](docs/FIX_LEDGER.md).

## 📖 О проекте

**XKeen Route** — это современная модульная система управления маршрутизацией, обходом блокировок и инфраструктурой прокси для роутеров Keenetic и Netcraze под управлением среды **Entware**.

Она работает автономно в виде единого бинарного файла на **Rust** (Axum 0.8 + Tokio), потребляет всего **~6–12 МБ ОЗУ** и практически нулевую нагрузку на процессор, отдавая реактивный веб-интерфейс (React SPA + TailwindCSS) на порту `1001`.

## 🔥 Киллер-фичи (Killer Features)

1. 🧠 **Smart Failover 2.0 (Двухуровневое резервирование Tier 1 VPS vs Tier 2 Белые списки)**
   - **Разделение узлов по тирам**: стандартные зарубежные VPS (`Tier 1`) и отечественные узлы белых списков (`Tier 2`). Переход на Tier 2 осуществляется **только при падении всех VPS**.
   - **Ускоренный 60с Canary Soak Test**: при возврате связи с Tier 1 запускается изолированный тест через локальный листенер `127.0.0.1:7894` со сбросом сокетов.
   - **Защита от «зомби-серверов» (Persistent Quarantine)**: автоматическая отправка нестабильных нод в карантин с сохранением в `/opt/etc/xkeen-route/quarantine.json`.
   - **Детектор «черных дыр» (Blackhole anomaly)**: обнаружение узлов, которые принимают трафик (upload > 5 КБ), но не отдают ответ (download = 0 на $\ge 3$ сокетах).
   - **Честный учет трафика**: устранена подмена каналов — трафик белых списков и VPS считается строго раздельно.

2. ⚡ **Двухъядерный Zapret DPI (Zapret 1.x vs Zapret 2.0 nfqws2) + CDN Boost (`/boost`)**
   - Бесшовное переключение на лету между классическим `nfqws` и модульным `nfqws2`.
   - **Mini-Blockcheck**: встроенный тест блокировок с автоматическим подбором лучшей стратегии desync в 1 клик.
   - **CDN Boost (`/boost`)**: умное обнаружение и добавление скрытых поддоменов и CDN в хостлист.
   - **Индивидуальный Zapret (DPI) per-device**: включение/выключение обхода для каждого клиента отдельно прямо из таблицы устройств.
   - Независимые модули для YouTube 4K (кэши GGC на скорости провайдера), Discord (включая UDP Voice RTC), обхода блокировок и комьюнити-хостлистов.

3. 🛡️ **Белые списки (Whitelist Isolation Mode)**
   - Преодоление изоляции и блокировок зарубежного трафика.
   - Три стратегии: **Полный туннель** (Full Tunnel), **Прямой доступ к подсетям** (Subnet Direct) и **Привязанный шлюз** (Pinned Node).
   - Встроенный каталог отечественных сервисов (госуслуги, банки, маркетплейсы, CDN) и авто-детектор пригодности серверов.

4. 🛡️ **Встроенный AdGuard Home**
   - Интерактивный дашборд блокировок, Query Log в реальном времени, управление правилами и DNS Rewrites.
   - **Анти-петлевая защита портов**: перенос DNS-сервера AdGuard на порт `5354` для исключения конфликтов с Fake-IP ядра Mihomo (`53/udp`).

5. 📱 **Раздельная маршрутизация per-device & per-server**
   - Привязка любого домашнего устройства к персональному серверу, политике или прямому выходу (`DIRECT`).
   - Индивидуальные доменные правила и временные расписания активности клиентов.
   - Управление скоростью клиентов через Keenetic RCI API.

6. 🎮 **Игровой режим (Smart Gaming) и Xbox DNS**
   - Распознавание игровых сессий (CS2, Dota 2, Valorant, Apex Legends, Steam, PSN, Xbox).
   - Автоматическая генерация командного файла `fix_xbox_dns.cmd` для моментального устранения проблем со входом в службы Microsoft/Xbox Live.

7. 🩺 **Диспетчер задач (htop в вебе) и Swap Manager**
   - Встроенный монитор процессов роутера с сортировкой по CPU/RAM и кнопкой завершения зависших процессов (`kill`).
   - Создание и управление файлом подкачки (Swap) на USB-диске для предотвращения Out-Of-Memory на роутерах с 128/256 МБ RAM.

### 📊 1. Дашборд (`Dashboard`)
Центральная панель мониторинга и мгновенного управления:
- **Метрики роутера**: загрузка CPU, температура процессора, RAM роутера и расход стека XKeen в целых числах.
- **Индикатор нехватки памяти**: адаптивный баннер `SwapRecommendationBanner` с предложением включить Swap в 1 клик при заполнении RAM.
- **Hero-карточка активного сервера**: бейдж статуса «🔵 В сети», протокол (VLESS, Shadowsocks и др.), текущий пинг и график RTT.
- **Модуль Smart Failover**:
  - Тумблер «🧠 Умный фейловер» (приоритет Tier 1 VPS перед Tier 2 БС).
  - Бейджи уровней серверов **Tier 1 (VPS)** и **Tier 2 (БС)**.
  - Честный объем трафика эпизодов белых списков без смешивания с основным прокси.
  - Журнал переключений с группировкой повторов (`×N`).
- **Спарклайн задержки (`PingSparkline`)**: компактная визуализация стабильности связи с миллисекундной точностью.
- **Быстрые действия**: экспресс-проверка доменов (`handleCheckDomain`), разблокировка в 1 клик и тумблер AdBlock.

### 🛰 2. Серверы и подписки (`Servers`)
Управление каталогом прокси-узлов и источниками подписок:
- **Широкая поддержка протоколов**: VLESS Reality, VMess, Shadowsocks, Trojan, Hysteria2, TUIC, WireGuard.
- **Интерактивные замеры**: параллельный пинг всех узлов (`Ctrl + P`), замер джиттера в реальном времени (`measureLiveJitter`) и встроенный Speedtest.
- **Умное исправление названий (`fixNames`)**: автоматическое исправление кракозябр (mojibake cp1251/cp866) в именах нод.
- **Фильтрация и поиск**: мгновенный поиск (`Ctrl + K`), фильтры по странам, подпискам и тегам.
- **Шеринг и экспорт (`ShareNodeModal`)**: генерация QR-кодов без тяжелых внешних библиотек (собственный легковесный алгоритм Reed-Solomon) и экспорт ссылок.
- **Генератор Outbound (`OutboundGeneratorModal`)**: конвертация ссылок в готовый блок `outbounds` для ручной вставки в YAML.
- **Управление провайдерами**: добавление по URL/файлу, назначение алиасов, привязка HWID для защищенных подписок, контроль квот и ручное обновление.
- **Списки исключений (`openIgnore`)**: драфт-режим выбора узлов, исключаемых из ротации пула failover.

### 📱 3. Устройства и политики (`Devices` & `DeviceRow`)

- **Карта политик (`PoliciesMap`)**: наглядная визуализация привязки сетевых сегментов к интерфейсам.

- **Синхронизация комьюнити-хостлистов**: автоматическое и ручное обновление баз заблокированных ресурсов.
- **6 готовых пресетов**: быстрая настройка под сценарии («Гейминг/Медиа», «Максимум ТСПУ», «Только YouTube»).
- **Аналитика перехвата**: счетчики перехваченных пакетов и сэкономленного трафика VPS.

### 🛡️ 8. AdGuard Home (`AdGuard`)
Сетевая блокировка рекламы и трекеров без сторонних расширений:
- **Сводная статистика**: общее число DNS-запросов, заблокированные запросы и процент фильтрации.
- **Журнал DNS-запросов (Query Log)**: просмотр всех запросов клиентов сети с быстрой блокировкой домена в 1 клик.
- **DNS Rewrites**: создание и удаление собственных переопределений доменов.
- **Управление правилами фильтрации**: добавление списков EasyList, AdGuard Base и пользовательских правил.
- **Управление сервисом**: запуск, остановка и установка пакета AdGuard прямо из веб-интерфейса.
- **Безопасная интеграция**: защита от циклических DNS-запросов между AdGuard и Mihomo.

### ⚙️ 12. Настройки, Task Manager и Бэкапы (`Settings`, `TaskManager`, `ConfigEditor`)
Центр администрирования системы:
- **Диспетчер задач (`TaskManager` / htop в вебе)**: просмотр всех системных процессов роутера, сортировка по CPU% и RAM RSS с возможностью принудительного завершения зависших процессов (`kill`).
- **Swap Manager**: создание файла подкачки на USB-диске роутера, выбор объема и безопасное отключение.
- **Тонкая настройка Failover 2.0**: параметры гистерезиса, интервалы опроса, пороги пинга и список карантина серверов.
- **Бэкапы и восстановление**: экспорт полного снимка конфигураций в JSON, импорт и восстановление в 1 клик.


> [!TIP]
> **Если `raw.githubusercontent.com` недоступен или заблокирован провайдером**, используйте зеркало:
> ```sh
> curl -Ls https://ghproxy.net/https://raw.githubusercontent.com/nickitafedorov2012-code/xkeen-ui-ext/main/setup.sh | sh
> ```

### 🕹 Управление сервисом

После установки панель доступна в браузере по адресу: **`http://<IP-роутера>:1001`** (например, `http://192.168.1.1:1001`).

Управление через системный init-скрипт Entware:
```sh
sh /opt/etc/init.d/S99xkeen-route start    # Запустить панель
sh /opt/etc/init.d/S99xkeen-route stop     # Остановить панель
sh /opt/etc/init.d/S99xkeen-route restart  # Перезапустить панель
sh /opt/etc/init.d/S99xkeen-route status   # Проверить статус процесса
```

## ⚙️ Конфигурация

Файл конфигурации расположен по пути `/opt/etc/xkeen-route/config.json`. Поддерживается автоматический deep-merge (неуказанные параметры берутся из безопасных значений по умолчанию):

```json
{
  "rci": {
    "host": "127.0.0.1",
    "port": 79,
    "login": "admin",
    "password": "",
    "token": ""
  },
  "mihomo": {
    "host": "127.0.0.1",
    "port": 9090,
    "secret": "",
    "config_path": "/opt/etc/mihomo/config.yaml"
  },
  "failover": {
    "enabled": true,
    "smart_failover_enabled": true,
    "ping_threshold_ms": 250,
    "priority_server": "de_vless",
    "priority_chain": [
      "de_vless",
      "nl_vless",
      "fi_trojan"
    ],
    "auto_restore_priority": true,
    "interval_secs": 45,
    "device_failover_enabled": true
  },
  "zapret": {
    "enabled": true,
    "hybrid_youtube": true,
    "hybrid_discord": true,
    "discord_voice_udp": true,
    "youtube_turbo": true,
    "general_bypass": true,
    "aggressive_dpi": false,
    "isolated_proxy": true
  },
  "adguard": {
    "enabled": true,
    "host": "127.0.0.1",
    "http_port": 3000,
    "dns_port": 5354
  },
  "refresh_interval_sec": 5,
  "adblock_enabled": true
}
```

> [!NOTE]
> **Авторизация в Keenetic RCI**: панель автоматически считывает токен `X-Ndma-Tkn` из `/opt/etc/xkeen/xkeen.json`. При отсутствии токена используется встроенная challenge-response авторизация по логину и паролю администратора.

## 🔧 Сборка из исходников

### 1. Сборка фронтенда (Node.js 18+):
```sh
cd frontend
npm install
npm run build
```

### 2. Сборка бэкенда (Rust 1.75+):
```sh
cd backend
cargo build --release
```

### 3. Локальная разработка (с Hot-Reload):
```sh
# Терминал 1: Запуск бэкенда на порту 1001
cd backend && cargo run

# Терминал 2: Запуск дев-сервера Vite с автоматическим проксированием /api -> :1001
cd frontend && npm run dev
```

### 4. Кросс-компиляция под роутеры (MIPS / MIPSle / ARM64 / ARMv7):
Автоматически выполняется через [GitHub Actions](.github/workflows/build.yml) или локально с помощью [`cross`](https://github.com/cross-rs/cross):
```sh
cross build --target mipsel-unknown-linux-musl --release
cross build --target mips-unknown-linux-musl --release
cross build --target aarch64-unknown-linux-musl --release
cross build --target armv7-unknown-linux-musleabihf --release
```

## ⚠️ Безопасность

Панель **не требует обязательного пароля при входе из доверенной локальной сети (LAN)** для быстрого доступа домашних устройств.

> [!CAUTION]
> **Никогда не пробрасывайте порт `1001` в публичный интернет напрямую (через DMZ или проброс портов).**
> Для удаленного доступа извне используйте VPN-серверы роутера (WireGuard, OpenVPN, IPsec) либо службу KeenDNS с обязательной авторизацией по паролю KeeneticOS. При необходимости можно включить встроенную авторизацию по паролю в настройках панели.

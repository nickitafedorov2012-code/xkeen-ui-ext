# Единый реестр дефектов XKeen Route (`AUDIT-001` — `AUDIT-123`)

**Методика и структура подсчёта (без двойного учёта и без «выдуманных» цифр):**
- **Канонических кластеров дефектов:** **`123`** = **`106`** уникальных находок статического аудита (`B1–B6` = `79`, `F1–F3` = `27`) + **`17`** самостоятельных дефектов, впервые воспроизведённых вживую на роутере `192.168.1.1` (`11` API/SSH `T00–T10b` + `1` post-reboot автозапуск `mihomo` + `5` браузерный аудит UI `T11`).
- **Распределение по критичности:** **P0 = `20`**, **P1 = `68`**, **P2 = `31`**, **P3 = `4`** (`20 + 68 + 31 + 4 = 123`).
- **Масштаб относительно оценки «500+ багов»:** многие кластеры являются составными (содержат 3–8 атомарных поломок — например, `AUDIT-005` объединяет 6 звеньев конвейера `free_sub` + ~30 битых VLESS URI в сидах; `AUDIT-084` и `AUDIT-098` объединяют по 6–7 дефектов инсталлера/обработчиков), плюс в `docs/BUG_AUDIT.md` остаётся **`46` неначатых + `8` `BLOCKED` + регрессировавшие пункты** (`05_LEGACY_AUDIT_RECONCILIATION.md`). Данный реестр даёт точную 100% проверяемую дедупликацию по исходному коду и железу.

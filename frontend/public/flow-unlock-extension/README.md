# 🔓 Flow Unlocker

**Расширение для браузеров Chrome / Edge для обхода региональной блокировки Google Flow (Google AI Sandbox).**

- **Автор:** [nickitafedorov2012](https://github.com/nickitafedorov2012-code)
- **Проект:** [XKeen Route](https://github.com/nickitafedorov2012-code/xkeen-ui-ext)
- **Версия:** 1.0.0

---

## ⚡ Установка в браузер (Chrome / Edge / Brave / Яндекс.Браузер)

1. Откройте в браузере страницу расширений:
   - В Google Chrome: `chrome://extensions`
   - В Microsoft Edge: `edge://extensions`
2. В правом верхнем углу включите тумблер **«Режим разработчика»** (Developer Mode).
3. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked).
4. Выберите эту папку (содержащую `manifest.json`).
5. Закрепите значок расширения на панели браузера.

---

## 🚀 Использование

1. Нажмите на иконку **Flow Unlocker** на панели расширений.
2. Убедитесь, что переключатель **«Разблокировка Flow»** включён.
3. Нажмите **«🚀 Открыть Google Flow»** или перейдите на [flow.google.com](https://flow.google.com/?authuser=0&hl=en).
4. Если ранее отображалась ошибка «Unsupported Country» — нажмите кнопку **«🔄 Перезагрузить вкладку Flow»** в плагине.
